This page contains my repository, which is free to use. For now, it only includes a modified version of the Estouchy skin. More add-ons or skins will be added in the future.

Provided I have the time and the inclination! :)


A bit about Estouchy – the skin is primarily designed for touch-enabled devices, but it also includes support for a keyboard and mouse, or a remote control.
Video playback controls have been slightly adjusted to make them easier to target with a finger, along with a few other minor tweaks.
